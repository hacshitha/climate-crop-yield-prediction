# Climate-Aware Crop Yield Prediction 🌱

## 📌 Project Overview
This project demonstrates a machine learning workflow for crop yield prediction using climate-related and agricultural features. It compares multiple regression models and evaluates their predictive performance using standard regression metrics.

## 🎯 Objectives
- Explore agricultural and climate-related data.
- Prepare data for machine learning.
- Train and compare regression models.
- Evaluate model performance using MAE, RMSE, and R².
- Visualize actual versus predicted crop yield values.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Machine Learning
- Regression Model Evaluation

## 🤖 Models
1. Dummy Regressor — baseline model
2. Linear Regression
3. Random Forest Regressor

## 📊 Evaluation Metrics
- **MAE:** Mean Absolute Error
- **RMSE:** Root Mean Squared Error
- **R² Score:** Measures how well predictions explain the variation in the target values.

## 🚀 How to Run

### 1. Clone the repository
```bash
git clone https://github.com/hacshitha/climate-crop-yield-prediction.git
cd climate-crop-yield-prediction
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the project
```bash
python crop_yield_analysis.py
```

Follow the script output to review model evaluation results and generated visualizations.

## ⚠️ Dataset Note
The sample dataset included in this repository is synthetic and intended for demonstrating the machine learning workflow. It does not establish real-world agricultural prediction accuracy. Real agricultural data must be used to validate model performance before drawing practical conclusions.
